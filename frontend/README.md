# 税枢云前端第一版

根据 `../docs/税枢云前端需求文档.md` 实现的本地演示工作台。技术栈为 Vue 3.5、TypeScript 5.6、Vite 6、Element Plus 2.9、Vue Router、Pinia 与 Vue Query。无真实企业数据及外部财税服务连接。

## 启动

使用 Node.js 22 或更高版本、pnpm 9：

```powershell
cd D:\DATA\税枢云\frontend
pnpm install
pnpm run gen-api
pnpm dev
```

打开 `http://127.0.0.1:5173`。登录页选择会计、税务人员或只读访客，密码均为 `demo123`。模拟服务仅在 Vite 开发模式启动；`dist` 是前端静态资源，需要后端配合，不能独立完成登录和业务操作。

当前工作区已安装依赖，也可双击 `start-dev.cmd` 启动，避免机器上其他版本的 pnpm 干扰。关闭终端即停止服务。

## 已实现

- 登录、原访问地址恢复、退出登录、三种演示角色的写权限校验。
- 侧栏折叠、主体切换、仪表盘四项指标、六个月样例趋势、待办跳转。
- 发票关键词、期间、状态筛选，分页，直达详情，模拟导入、重复校验、查验。
- 建议依据与三项权重展示、人工确认、满足门槛的批量采纳、只读凭证。
- 风险指派、调查和关闭，报销样例只读；其他模块统一占位。
- 单一鉴权 SSE 连接、断线重连补查、查询失效刷新、固定演示 AI 问答。
- 模拟状态落盘至忽略的 `.demo/state.json`，重启服务仍保留票据和凭证。会话仅存在服务内存，重启后需重新登录。

## 演示契约与真实后端边界

前端第一版开发时缺少交接文档及 FastAPI 后端，依据用户指定的前端需求文档开发。2026-11-17 已补充 [后端交接文档](../docs/CODEX-HANDOFF.md)，后端尚待实现，联调迁移要求见其 §8。`demo/openapi.json` 是明确标记的临时演示契约，不代表已确认的生产接口。通过 `pnpm run gen-api` 自动生成 `src/api/schema.d.ts`，没有手写 API 数据类型。`demo/build-contract.mjs` 维护该演示 OpenAPI。

生产接入时将 gen-api 输入替换为 FastAPI OpenAPI，并逐项确认需求文档 §7 的字段、权限、幂等、SSE 鉴权及错误结构。模拟服务基于 Vite 中间件和 Node 标准库，仅用于开发，不替代 Python/FastAPI 技术栈，不具备 PostgreSQL RLS、多进程事务、生产认证或真实税务能力。

所有票据、建议、凭证、风险和计数由模拟服务持有，Vue Query 缓存查询结果，Pinia 只存会话、主体和侧栏状态。没有浏览器 localStorage 票据副本。示例科目、固定税额和置信度仅用于演示，不作为真实核算规则。申报目前是 T12 占位；没有宣称完成税率表读取、税额计算、台账追溯或模拟申报。

## 验证

```powershell
pnpm run gen-api
pnpm run typecheck
pnpm test
pnpm run build
```

自动测试覆盖权限、跨主体访问、重复采集、查验前置状态、幂等重试、落盘恢复、借贷平衡、置信度依据、批量门槛、分页筛选、风险状态和 SSE 通知。桌面验收尺寸为 1440px、1280px；窄屏允许表格内部横向滚动。

## 快速体验

会计登录 → 发票中心 → 模拟导入 → 模拟查验 → 生成入账建议 → 展开依据 → 采纳建议 → 查看凭证 → 刷新页面确认已入账。再次导入相同票号可检查冲突提示。切换只读访客可检查写操作不可用。
